# 06 · 工艺规则与交付自检

## 按工艺的最小值（写进 `checks`）

| 工艺 | `minWall` | `minCorner` | 拔模 | 其他硬约束 |
|---|---|---|---|---|
| FDM 打印 | 1.2 | 0.8 | 0 | 悬空面 ≤45°；层纹方向垂直于主要受力；螺纹孔用 Ød−0.2 自攻 |
| SLA/DLP | 0.8 | 0.5 | 0 | 封闭腔需 ≥Ø3 排液孔；避免大平面直接贴底 |
| 注塑 | 1.5–2.5 | 1.0 | 1–2° | 壁厚差 ≤15%；筋厚 = 0.6×壁厚；圆角内 R ≥ 0.5×壁厚 |
| CNC 铝 | 1.0 | 1.0（≥刀半径） | 0 | 内直角必须给 R；深腔深宽比 ≤3；避免侧向欠刀 |
| 钣金 | = 板厚 | ≥ 板厚 | 0 | 折弯边距 ≥ 2×板厚 + R；孔边距 ≥ 1.5×板厚 |

## 五条容易踩的结构坑

1. **铰链壁厚**：销轴孔周围的材料至少要 2×孔径，否则打印件一掰就裂。侧耳做 3mm 起。
2. **卡扣不是刚体**：spec 里的卡扣用几何近似表达，不做弹性仿真。真正的卡扣要留 0.5mm 干涉量 + 长悬臂。
3. **薄壁与拔模冲突**：拔模 1° 在 100mm 高的面上会吃掉 1.75mm 侧向余量，高件慎用。
4. **配重/重心**：底座加空腔（`cut`）会减重，但也会把重心抬高；用「稳定性分析」确认倾覆角仍 >18°。
5. **打印方向**：层间强度最弱。承力方向尽量落在 XY 平面内，必要时改 spec 的模型朝向（不是改工艺）。

## 交付前自检清单

**spec 层**

- [ ] `--check` 无 error
- [ ] 每个参数都有 `min/max`，且 `value` 在范围内
- [ ] 所有 `$param` 引用都能解析
- [ ] `joints.rest` 落在 `range` 内
- [ ] 切除特征的 `offset` 比目标面多 0.2–0.3mm
- [ ] `checks.minWall` 与 `meta.process` 匹配（见上表）

**预演层**

- [ ] 造型模式：一眼能看出是什么、怎么用；无悬空薄片、无穿模
- [ ] 物理模式：全行程最小间隙 > `minClearance`；重力力矩已记录；倾覆角 > 18°
- [ ] 图纸模式：三视图轮廓完整、总尺寸与 KPI 一致、比例是标准值

**建模层**

- [ ] `report.json` 的 `failed` 为空（或每条失败都有明确原因与替代方案）
- [ ] SLDPRT / STEP / STL 三个文件都生成
- [ ] SW 回读质量与预演估算质量偏差 < 25%
- [ ] 装配体在 SW 里做一次「干涉检查」，结论与预演一致

**交付物**

- [ ] `spec.json`（可改参数）
- [ ] 预览截图（造型 / 物理 / 图纸各一张）
- [ ] `part.SLDPRT` + `part.step`（+ `part.stl` 若为打印件）
- [ ] `report.json`
- [ ] 一页纸说明：设计意图、关键参数范围、已知限制、下一步建议

## 常见设计缺陷对照表

| 现象 | 可能原因 | 修法 |
|---|---|---|
| 预演质量比 SW 回读小很多 | 有特征没生效（拉伸失败） | 看 report.failed，逐个修 |
| 预演质量比 SW 大很多 | 切除没穿透/位置偏 | 检查 cut 的 offset 与 dir |
| 图纸总高与 KPI 不一致 | 关节姿态不同（图纸按 rest） | 确认 `joints.rest` 与期望姿态一致 |
| 关节扫掠时角度到不了 `range` 上限 | 有干涉 | 看「最小间隙」，减薄或改行程 |
| 倾斜一点点就翻 | 重心高/底面小 | 加宽底面、加配重腔、降低高度 |
| 打印出来铰链断了 | 销孔壁太薄 / 层纹垂直受力 | 加厚耳板、改打印方向 |

## 已知限制（写进交付说明，别装作没有）

1. 只支持「草图 + 拉伸/切除」的特征族，自由曲面、扫描、放样、变截面一律不覆盖。
2. 关节只有单层转动副，无齿轮/连杆/柔性铰。
3. 物理预演是**刚体运动学 + 解析力学**（重心、力矩、AABB 间隙），不是有限元，不做应力/疲劳。
4. 图纸是包围盒投影的概念图，不是可下厂的施工图。
5. SolidWorks 侧的特征重建依赖 API 版本，圆角/工程图属 best-effort，失败会显式记录。
