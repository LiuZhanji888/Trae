# 04 · 浏览器预演与出图

`assets/viewer.html` 是一个单页应用：读 `spec.json` → 用 three.js 现场生成几何 → 三个模式看同一个模型。
它的价值不是「好看」，而是**在打开 SolidWorks 之前就把设计问题暴露出来**。

## 启动

```bash
cd <项目>/cad
python3 -m http.server 8123
# 浏览器打开 http://localhost:8123/viewer.html?spec=./spec.json
```

- 必须走 http，不能用 `file://`（ES module + fetch 会被浏览器拦）。
- `?spec=` 可省略，默认读同目录 `example_spec.json`；读不到时回落到内置示例并在日志里提示。
- three.js 从 unpkg CDN 加载。若环境无外网：把 `three.module.js` 与 `examples/jsm/controls/OrbitControls.js`
  下载到 `cad/vendor/`，改 `viewer.html` 里的 importmap 指向即可。

## 三个模式

### 造型模式（默认）

- 拖动旋转 / 滚轮缩放；PBR 材质 + 三点光 + 接触阴影。
- 右侧「参数」滑块实时重建几何 —— 这是做尺寸收敛最快的方式，先拖到顺眼再回写 spec。
- 左侧 HUD 显示体积 / 质量 / 重心 / 特征数。
- 看什么：体块比例是否成立、有没有「薄得像纸」的悬空面、圆角是否被吃掉。

> 切除特征在预览里是**深色填充代理**（不做真布尔），用于读位置和大小；真实布尔以 SolidWorks 为准。

### 物理模式

点「▶ 运动扫掠」后，关节做往复运动，实时读四个数：

| 指标 | 含义 | 判定 |
|---|---|---|
| 当前角度 | 关节实时角度 | 应在 `range` 内 |
| 重力力矩 | `m·g·力臂`，子件绕轴自重的力矩（N·m） | 决定限位块/阻尼/弹簧需要多强；> 0.3 N·m 建议加摩擦或卡位 |
| 最小间隙 | 运动件与其他件的 AABB 最小距离 | 必须 > `checks.minClearance`（建议 ≥0.4mm）；为 0 说明干涉 |
| 倾覆角 | 重心投影到支撑边界的余量对应的倾角 | > 18° 安全；< 12° 需要加大底面或配重 |

「📍 稳定性分析」按底面（最低 10mm 内的特征）计算支撑多边形与重心，写入日志。

> AABB 是包围盒近似：细长斜置件会误报干涉。最终以 SW 装配体的「干涉检查」为准。

### 图纸模式

由 spec 的包围盒直接投影生成的三视图（主视 X-Y / 俯视 X-Z / 左视 Z-Y）+ 总长总高总深 + 标题栏（名称/材料/比例/版本）。
切除特征画虚线，实体画实线。

这是**概念图**，不是可交付的施工图：

| 有 | 没有 |
|---|---|
| 三视图轮廓、总尺寸、比例、标题栏 | 剖视图、局部放大 |
| 减重槽/孔的虚线投影 | 完整尺寸链、公差、GD&T |
| 质量/材料/工艺信息 | 焊接符号、表面粗糙度 |

需要正式工程图时，用 `sw_build.py --drawing` 在 SW 里生成带模型关联的视图，再人工补标注。

## 推荐的迭代节奏

1. 先只调**总尺寸三个参数**（宽/深/高），把体块定下来。
2. 再调**结构参数**（臂长、角度、壁厚），在物理模式看力矩与间隙。
3. 最后调**细节参数**（圆角、孔距），切图纸模式看轮廓是否干净。
4. 每一轮把最终值回写到 `spec.json` 的 `params[].value`，**不要在浏览器里改完就忘了**。

## 用 agent 操作浏览器时的要点

- 让浏览器子代理做的事：打开 URL → 截图 → 点「物理」→ 点「运动扫掠」→ 读面板数字 → 切「图纸」截图。
- 不要让它改文件；截图与读数回传给主 agent，由主 agent 改 spec。
- 每轮至少校验三件事：页面标题 = 项目名、无「初始化失败」、日志区没有红色（bad）行。

## 常见故障

| 现象 | 原因 | 处理 |
|---|---|---|
| 一直显示「正在加载 spec…」 | CDN 加载失败 / 控制台 importmap 报错 | 改用本地 vendor 的 three.js；确认 `spec-core.js` 与 html 同目录 |
| 模型全黑 | 法向反了（切除代理朝内） | 属正常代理表现；若实体发黑，检查 `extrude.dir` 与平面选择 |
| 参数滑块拖动无变化 | 表达式没引用该参数 | 在 spec 里把该参数用 `$key` 接进特征 |
| 图纸空白 | 无 `add` 特征或包围盒为 0 | `--check` 校验 spec |
| 构件错位 | `sketch.offset` 的符号方向理解反了 | 见 03 的坐标表，`top` 平面 v 轴朝 −Z |
