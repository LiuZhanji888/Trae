# 02 · 创意发散：三方向矩阵

创意不是凭空来的，是**约束的重新组合**。用三轴矩阵强制产出差异，而不是在一个方向上微调。

## 三轴

| 轴 | 可选项（各取其一） |
|---|---|
| **形态** Form | 折叠 / 嵌套 / 悬浮（单点支撑）/ 包裹（壳+盖）/ 生长（镂空骨架）/ 反向（把结构外露） |
| **结构** Structure | 单件打印 / 两件对合卡扣 / 磁吸模块 / 铰链+限位 / 弹性臂（无铰链活铰）/ 滑轨 |
| **材料·工艺** Material | 同种塑料 / 软硬双料（TPU 垫）/ 塑料+铝型材 / 板材折弯 / 打印+标准件 |

每个方向 = 一个形态 × 一个结构 × 一个材料组合，必须能一句话说清「为什么这样组合」。

## 输出格式（每个方向 5 行）

```
方案 A ·【折叠 + 铰链限位 + PETG 单件】
概念：底座与支撑臂铰接，靠限位块停在 65°，合上即收纳成 12mm 厚。
差异点：唯一能「收纳」的方案，厚度最优。
预估：92×70×12（合）/ 92×70×115（开），~90g，单件打印无支撑。
风险：铰链是薄弱环节，需要 3mm 轴径 + 两侧耳板；打印层纹方向要垂直于销轴。
```

## 评分表（用于推荐，不是替用户决定）

| 维度 | 权重 | 打分依据 |
|---|---|---|
| 功能达成 | 30% | 是否满足简报里的 3 条成功判据 |
| 可制造性 | 25% | 是否需要支撑/二次加工/专用刀具 |
| 结构可靠性 | 20% | 薄弱环节数量、应力集中、疲劳 |
| 成本/重量 | 15% | 材料体积、标准件数量 |
| 创意度 | 10% | 是否给出用户没想到的解 |

在对话里给出 3 个方案的分数与推荐项，并说明**推荐理由的一句话**。用户没有偏好时选分数最高者。

## 发散时的四个自检

1. **能不能少一个零件？** 两件对合能变一件活铰吗？
2. **能不能少一个工序？** 需要后粘接/后攻丝吗？能否打印出来就是成品？
3. **薄的地方会不会先坏？** 每个 <2mm 的截面都要问一次。
4. **用户会不会用错？** 有没有防呆（不对称、导向角、唯一装配方向）。

## 从方案到 spec 的映射

| 方案里的说法 | 落到 spec |
|---|---|
| 「底座」「支撑臂」 | `parts[]` |
| 「铰接」「限位」「卡扣」 | `joints[]`（revolute + range + rest）；卡扣用特征近似，不做柔性仿真 |
| 「减重」「镂空」 | `op:"cut"` 特征 |
| 「65° 停止」 | `joints[].rest` + 一个物理限位特征（挡块） |
| 「合上 12mm 厚」 | `params` 的收纳厚度 + `checks` |

> 若方案里有 spec 表达不了的自由曲面，**在发散阶段就淘汰它**，换一个能用「草图+拉伸」表达的近似形态。这是本流水线能自动化的前提。
